# Milestones: Netflix User Behavior Project

## Milestone 1: Data Preparation
- Clean and preprocess Kaggle dataset.  
- Integrate OMDB/TMDB API for content metadata.  
- Merge datasets into analysis-ready format.

## Milestone 2: Exploratory Analysis
- Generate summary statistics of watch history.  
- Visualize genre, duration, and user engagement patterns.  
- Analyze subscription trends and retention metrics.

## Milestone 3: Trend Analysis
- Identify trending content over time.  
- Integrate external ratings and popularity metrics.  
- Visualize top genres, movies, and content patterns.

## Milestone 4: Prediction Model
- Train machine learning model to predict churn.  
- Evaluate model performance with accuracy, precision, recall.  
    - is the model performrance > 0.7 f1 score?
    - when we input specific user information, can we get the churn decision right away?
- Visualize churn probabilities and feature importance.

## Milestone 5: Documentation & Reporting
- Write Functional Specification and Component Specification.  
- Create interaction diagrams for all use cases.  
- Compile project summary and final README for GitHub.
